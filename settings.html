Маршруты
ОткудаКудаМин. цена, ₽
«Откуда» и «Куда» — город, склад или часть адреса (например москва, никольское). Несколько вариантов — через запятую (москва, дмитров). Совпадение идёт по целым словам: «краснодар» не найдёт «Краснодарский край». Чтобы искать по началу слова, добавьте * (москов*). Пусто — любое направление. Минимальная цена — рейс подходит, если цена не ниже. 0 — без ограничения.

Проверка Страниц × 40 рейсов. 10 = первые 400 рейсов списка.
Telegram

Бота создаёт @BotFather. Каждый получатель должен сначала написать боту /start. Свой chat ID можно узнать у @userinfobot.
WhatsApp (Wappi)

Profile ID и токен — в личном кабинете wappi.pro на странице профиля (WhatsApp должен быть авторизован по QR-коду).
Токены хранятся только в этом браузере (chrome.storage.local) и не синхронизируются через аккаунт Google.
