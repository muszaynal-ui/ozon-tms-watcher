# Ozon TMS — мониторинг рейсов

Chrome-расширение (MV3): периодически обновляет tms.ozon.ru/cargoes, прокручивает список до конца и уведомляет о новых рейсах по заданным правилам.

## Установка
1. `chrome://extensions` → «Режим разработчика» → «Загрузить распакованное» → папка проекта.
2. В popup задайте правила, нажмите «Сохранить», включите мониторинг.

## Автообновление
Расширение раз в час сверяет `version` в `manifest.json` на ветке `main`.
Один раз откройте popup → «Обновления» → «Выбрать папку расширения». Дальше файлы обновляются сами и расширение перезагружается.
Чтобы выпустить обновление: поднимите `version` в `manifest.json` и сделайте push в `main`.
